# About Simple Ecommerce App

Simple Ecommerce App is a lightweight, modular web application designed to demonstrate the core features of an ecommerce platform using Java and Spring Boot. The project is structured for clarity and maintainability, making it ideal for learning, prototyping, or extending into a full-featured solution.

## Key Features
- **User Management:** Register, update, and manage users.
- **Admin Management:** Admin roles for managing products and orders.
- **Product Management:** Add, update, and list products.
- **Order Management:** Place and track orders.
- **RESTful API:** Clean separation of concerns using entities, repositories, and services.

## Technologies Used
- Java 21 LTS
- Spring Boot
- Spring Data JPA
- Maven

## Project Goals
- Provide a simple, understandable codebase for ecommerce basics
- Demonstrate best practices in Java and Spring Boot development
- Serve as a foundation for more advanced ecommerce features
